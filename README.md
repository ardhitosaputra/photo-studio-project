# 📸 Photo Studio

> **A Minimalist Photobooth Web Application**  
> Capture, edit with filters & stickers, add frames, print photocards, and share seamlessly.

---

## ✨ Features

- 📷 **Live Camera & Multi-shot Capture**: Real-time camera feed with countdown timer, mirror flip, flash effect, and multi-shot modes (Single, Photo Strip, 2×2 Grid).
- 🎨 **Creative Filters**: Real-time preset filters (B&W, Sepia, Vintage, Warm, Cool, Dramatic, Fade, Noir, Vivid, Pastel, Retro).
- 🏷️ **Stickers & Props**: Emoji, props, text badges, and decorative stickers with drag-and-drop support.
- 🖼️ **Aesthetic Frames**: Polaroid, vintage border, neon glow, minimalist frame, 35mm film strip, and gradient styles.
- 🖨️ **Print-Ready Photocard**: Export layouts optimized for printing with dedicated print styles.
- 📱 **Social Sharing**: Native Web Share API integration with social media fallback links (WhatsApp, Instagram, Twitter/X, Facebook).
- ☁️ **Cloud Storage**: Save snapshots directly to Google Drive.

---

## 🛠️ Tech Stack

- **Core**: Vanilla JavaScript (ES2022+), HTML5, Canvas 2D API
- **Styling**: Vanilla CSS (Custom Properties, Glassmorphism, Dark Mode)
- **Build Tool**: [Vite](https://vite.dev/)
- **Icons**: SVG Icon System (Lucide style)
- **Typography**: Space Grotesk & Inter (Google Fonts)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- Modern web browser with camera access (Chrome, Edge, Safari, Firefox)

### Installation

```bash
# Clone the repository
git clone https://github.com/ardhitosaputra/photo-studio-project.git

# Navigate to project directory
cd photo-studio-project

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
npm run preview
```
